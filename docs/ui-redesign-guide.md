# PenKaku UI 重组排列与观感优化指导文档

> **诊断基线**：通过 `PENKAKU_FAKE=1` 启动 `penkaku.exe`（默认窗口 `1180×760` 逻辑像素 / `1792×1151` 物理像素，`scale_factor = 1.5`），结合 `agent-desktop` 实机截图与 UI Automation（UIA）无障碍树快照，对照 `crates/penkaku-gui/src/` 全量源码完成审计。

---

## 1. 现状实测问题清单

通过 `agent-desktop` 实机运行截图与 `snapshot` 树抓取，定位出以下直接影响可用性与视觉观感的问题：

| 级别 | 现象与根因 | 涉及文件 |
| --- | --- | --- |
| **P0** | **「开始」选项卡空间分配与使用频率倒置**：低频配置 `中英文`（`SCRIPT_GROUP_W = 256.0`）占用了全栏最大宽度，甚至宽于核心组 `字体`（`224.0`）与 `段落`（`132.0`）；而高频入口（字体库直达、查找/替换、当前模板快切、一键书写/导出）缺失或藏在下拉框内；`编辑` 组的 `撤销`/`重做` 与标题栏快速访问工具栏重复。 | `crates/penkaku-gui/src/app/ribbon_tabs.rs` |
| **P0** | **「首行缩进 (Tab)」图标渲染为空白**：UIA 树中存在 `首行缩进 (Tab)` 按钮，但画布中 `段落` 第一行第 5 个图标位置为空白透明（`IconName::ListIndentIncrease` 在当前图标资源映射中未正确渲染）。 | `crates/penkaku-gui/src/app/ribbon_tabs.rs`、`crates/penkaku-gui/src/icons.rs` |
| **P0** | **右侧任务窗格职责混杂且严重挤压**：任务窗格顶部标题硬编码为 `设备`，但点击 `开始 › 段落 › 字符微调` 后，`tune_card` 与 `resume_card` 直接堆叠在 `DevicePanel` 上方；在 `760px` 默认高度下，`字符微调` 占据约 `300px`，将核心的 `点动与笔`、`书写任务`、`控制台`、`自定义命令` 全部挤出首屏。 | `crates/penkaku-gui/src/app.rs`（`task_pane`）、`crates/penkaku-gui/src/app/tune.rs` |
| **P0** | **「字符微调」标签列宽过窄导致全部折行**：`tune_card` 中行标签宽度 `w(px(40.))` 小于 14px 字体下 `字体：`、`字号：`、`轻重：`、`微调：` 的实际渲染宽度，导致 4 个标签全部折成两竖行（`字\n体：` 等），破坏对齐与紧凑感。 | `crates/penkaku-gui/src/app/tune.rs` |
| **P1** | **Notification 浮层遮挡 Ribbon 操作区**：连接设备或提示类 Toast 出现在窗口右上角，直接压住 `开始` 页最右侧 `编辑` 组（`全选` 被完全遮住）及右上角 `折叠功能区` 按钮。 | `crates/penkaku-gui/src/app.rs`、通知挂点配置 |
| **P1** | **「文件」标签缺乏 Backstage 视觉区隔**：代码注释要求 Word 风格的填充色 `文件` 标签，但 `ribbon::tab_item` 将 `文件` 渲染成与 `开始`/`布局`/`手写`/`设备`/`视图` 完全相同的纯文字样式，难以一眼识别其全局菜单入口属性。 | `crates/penkaku-gui/src/app.rs`（`tab_strip`）、`crates/penkaku-gui/src/ribbon.rs` |
| **P1** | **「手写」选项卡空旷而核心调参被深藏**：`手写` 页只有 4 个小分组，右侧大片留白，而用户最常调整的字距、上下浮动、缩放、旋转、扭曲/倾斜强度、连笔概率等全部藏在 `10px` 大小的 `↘` 对话框启动按钮之后。 | `crates/penkaku-gui/src/app/ribbon_tabs.rs`（`tab_style`）、`crates/penkaku-gui/src/style_dialog.rs` |
| **P1** | **「手写效果范围」弹窗遮挡预览且控件细节不统一**：模态窗居中弹出直接挡住中间书写画布，调参时无法看清字形变化；`NumberInput` 单位后缀间距不统一（`100 %`、`0.5mm`、`1 mm`）；底部缺少关闭按钮且暴露内部同步提示（`"范围数值需重新打开本窗口才会刷新"`）。 | `crates/penkaku-gui/src/style_dialog.rs` |
| **P1** | **跨区域重复入口与稀疏页签**：`从炽写导入` 在 3 处重复（`手写`、`设备 › 参数设置`、`文件 › 选项`）；`单页/双页` 与 `缩放` 在 `视图` 页与底部状态栏完全重复；`设备` 页与右侧 `DevicePanel` 均放置 `连接/断开`、`暂停/停止`，但高频校验工具 `落笔校准…` 仅存在于右侧面板中。 | `crates/penkaku-gui/src/app/ribbon_tabs.rs`、`device.rs`、`device_params.rs`、`backstage.rs` |
| **P2** | **UIA 无障碍树与自动化可读性缺失**：Ribbon 选项卡与状态栏单元格使用裸 `div` 绑定 `on_click`，对 UIA/读屏器完全不可见；`粘贴` 按钮、字体 `Select`、缩放 `Slider` 缺少可读 `name`；`StyleDialog` 两个复选框同名 `"同中文"`，`中英文` 两个按钮同名 `"字形"`，触发 `AMBIGUOUS_TARGET`。 | `crates/penkaku-gui/src/ribbon.rs`、`app.rs`、`style_dialog.rs`、`ribbon_tabs.rs` |

## 2. 按「使用频率 × 业务重要性」的功能分级矩阵

围绕手写绘图机（`文本/文档编辑 → 字体与手写风格化 → 版式与模板套打 → 联机校准与书写/导出`）核心闭环，将现有全部功能划分为 4 个优先级层级：

| 优先级 | 分类定位 | 包含功能 | 界面落位原则 |
| --- | --- | --- | --- |
| **P0** | **核心高频**<br>（每次必用） | 文档保存 / 撤销 / 重做；主字体切换与字体库入口；字号与快速缩放（`A+`/`A-`）；笔色；倾斜 / 下划线 / 标题 / 清除格式；段落对齐与首行缩进；当前模板切换；页码/字数/缺字/标点异常反馈；设备连接状态与**一键书写当前页 / 暂停 / 停止**；画布缩放与单/双页切换 | 标题栏 QAT + 「开始」主区 + 底部状态栏，零折叠、一跳直达 |
| **P1** | **中频关键**<br>（每份文稿必用） | 粘贴 / 剪切 / 复制 / 格式刷；查找与替换；字符微调（位置/大小/变形/轻重/应用至同字符）；手写风格开关（随机排布/变形/连笔）与核心强度/字距/浮动调节；换一组（笔迹种子）；纸张大小/方向/页边距/行距；点动与笔（步长/方向/抬落笔/设原点/回原点）；巡边；落笔校准；断点续写；导出 G-code / PDF / 打印 | 各一级选项卡主视觉区或独立上下文侧栏，不藏于极小 `↘` 按钮内 |
| **P2** | **低频辅助 / 条件功能**<br>（特定场景使用） | 英文与数字独立字体/比例/基线；中英空格与标点空格清理；排版规则（避头尾、作文格字母成对、作文格分词）；表格功能（上/下格、批量溢出、批量导入、刷新数据）；绘制框架线；上传 ESP32 SD 卡；辅助显示（格线/行号/页码）；深色模式 | 二级折叠组、上下文高亮分组（仅作文格/表格时显现）或「页面 / 视图」次级区域 |
| **P3** | **一次性 / 工程与系统级**<br>（初始配置或排障） | 串口端口选择与刷新；原始串口控制台与日志；自定义 G-code 命令；机器 `$` 固件参数；设备硬件参数（电机/舵机/速度/行程/坐标反向）；字体/模板目录设置与全局字体修复（`FontFix`）；账户登录/退出；从炽写导入迁移（`config.ini` / `.cset` / `.cx`） | 右侧面板底部可折叠抽屉、次级标签页、或统一收口至「文件 › 选项」迁移中心 |

## 3. 整体信息架构（IA）重组方案

### 3.1 窗口宏观四层结构

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [写]  保存 撤销 重做 | 查找        文档1 - PenKaku       ● 已连接模拟设备 | 登录  − □ × │  ← 标题栏 (36px)
├──────────────────────────────────────────────────────────────────────────────┤
│ [文件]  开始   页面   手写   设备   视图   [表格工具*]                        ^ │  ← Tab Strip (34px)
├──────────────────────────────────────────────────────────────────────────────┤
│  Ribbon 功能区卡片（高度保持 96~100px，组内严格 3 行对齐，重要操作用 big 按钮）      │  ← Ribbon (100px)
├──────────────┬───────────────────────────────────────────────┬───────────────┤
│ 左侧导航窗格  │                 画布编辑区                      │ 右侧检查器     │
│ (按需展开)    │   [FindBar 按需顶置]                           │ [设备 | 微调]  │
│  搜索 / 缺字  │   页面画布 + 蓝色书写原点 + 悬浮 MiniBar         │  互斥标签页    │
├──────────────┴───────────────────────────────────────────────┴───────────────┤
│ 第 2 页,共 2 页 | 805 字 | ▲ 缺字 1:写 | ▲ 标点异常 | 字体 | 模板   单/双页 ──●── 100% │  ← 状态栏 (24px)
└──────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 标题栏（`title_bar`）与 Tab Strip 优化

1. **标题栏右侧增设「设备状态胶囊」**：
   - 将原本藏在底部状态栏最中间的设备状态绿点提权为标题栏右侧（账户按钮左侧）的紧凑胶囊（如 `● 模拟设备 · 空闲` / `○ 未连接设备`）。
   - 点击直接切换右侧边栏到「设备」Tab，无需去底部状态栏寻找或切到「设备」选项卡。
2. **「文件」按钮采用强视觉区分**：
   - 将 `文件` 改为实心主色圆角胶囊（`bg(theme.primary)`、`text_color(theme.primary_foreground)`，高度 `26px`、圆角 `rounded_t_md()` 或 `rounded_md()`），在浅色与深色模式下都能一眼与功能选项卡区隔。
3. **Tab 命名与顺序重排**：
   - 调整为：**`文件`** | **`开始`** | **`页面`**（原「布局」）| **`手写`** | **`设备`** | **`视图`**。
   - **「布局」改名为「页面」**：因为该页核心职责是模板画廊、纸张尺寸、页边距与行距；而字符级/段落级排版在「开始」。
   - **「表格功能」升级为上下文组/上下文 Tab**：当当前模板为 `Ruling::Table` 时，在 `开始` 末尾（或带高亮底色的条件选项卡 `[表格]`）展示，并用 1px 主色顶边或浅主色背景条提示其上下文属性，避免常驻占宽。

## 4. 各区域与选项卡详细重组规范

### 4.1 「开始」选项卡（高频核心重构）

**改造目标**：让用户 80% 的日常操作（选字、改字号、换笔色、调格式、选模板、查缺字/查找、直接开始写）全部留在「开始」第一屏；把低频的「中英文独立比例/字体」与重复的「撤销/重做」移走。

**重组后分组顺序（左 → 右）**：

| 顺序 | 分组名 | 内部控件排列（严格 3 行栅格 / `big` 大按钮） | 调整理由与变更点 |
| --- | --- | --- | --- |
| **1** | **剪贴板** | 左侧 `big`: 粘贴<br>右侧 3 行 `small`: 剪切 / 复制 / 格式刷 | 保留 Word 心智习惯；**必须补全 `粘贴` 按钮的 UIA `name`**。 |
| **2** | **字体与笔色** | Row 1: 字体下拉框 `Select`（首项置顶 `打开字体库…` 并加分割线）<br>Row 2: 字号 `NumberInput` + `A↑` + `A↓` + **笔色按钮（图标下方加 3px 当前颜色横条）**<br>Row 3: `倾斜 ▾` / `下划线` / `删除线` / `上标` / `下标` / `标题（改用直观样式图标或 "标题" 短文本）` / `清除格式` | 保持高效率；修复 `标题` (`H`) 图标表意不清和 `笔色` 无当前色反馈的问题。 |
| **3** | **段落与微调** | Row 1: `左对齐` / `居中` / `右对齐` / `两端对齐` / **`首行缩进`（修复缺失图标）**<br>Row 2: `行距` 快捷数值（自由空白页启用，非空白页显示 `"模板行距"` 灰显提示）或 `中英/标点空格` 快捷菜单<br>Row 3: `字符微调`（点击切换右侧边栏至「字符微调」Tab）+ **条件按钮 `合并内容`（仅在 `Ruling::Grid` 作文格模板下显示，非作文格直接隐藏而非长期灰显占位）** | 释放无效占位的 `合并内容`；把原本放进 `布局` 的高频自由行距或空格清理上提；修复 `ListIndentIncrease` 空白图标 Bug。 |
| **4** | **编辑与检查** | 3 行 `small` 堆叠（或 `big` 查找 + 堆叠）：<br>- `查找`（打开左侧导航搜索）<br>- `替换`（打开顶部 `FindBar`）<br>- `文本清理 ▾`（下拉含：`全选`、`消除中英空格`、`消除标点空格`） | 删除与标题栏 QAT 重复的 `撤销`/`重做`；补齐编辑器核心高频的 `查找`/`替换`；把 `中英空格`/`标点空格` 收纳进统一菜单。 |
| **5** | **书写与输出** | 右侧收尾黄金位：<br>- `big` 主色强调按钮：**`书写`**（当设备已连接时主色高亮；未连接时点击提示连接并弹出设备侧栏）<br>- `small` 堆叠：`选页（第 X / N 页 ▾）` / `导出 G-code…` / `设备面板` | **核心工作流闭环**：写完字不必切到「设备」Tab 即可在「开始」页直接选页书写或导出。 |
| *(条件)* | **表格工具** | 仅当 `table == true` 时显示：保留 `上一格/下一格`、`批量溢出 (N)`、`批量导入…`、`刷新数据 ▾`，组背景加 `theme.primary.opacity(0.06)` 区分。 | 维持条件显隐，通过微弱主题色背景提高上下文辨识度。 |

> **移出项去向**：原 `开始` 中占 `256px` 的 `中英文`（`英文/数字` 字体、比例、字形按钮）整体迁移至 **「手写」选项卡**，使「开始」总宽度大幅瘦身，即使在 `900px~1180px` 窗口下也不再拥挤。

### 4.2 「页面」选项卡（原「布局」）

**改造目标**：理顺「模板优先，自由纸张其次」的逻辑，消除 `纸张大小/边距` 与 `页面尺寸（模板管理）` 之间的概念冲突。

**重组后分组顺序（左 → 右）**：

| 顺序 | 分组名 | 内部控件排列 | 调整理由与变更点 |
| --- | --- | --- | --- |
| **1** | **模板** | 横向模板预览画廊（`空白页` + 已有模板，**增大每张卡片可点击区至 `68×74px`**，选中态加粗边框与标签高亮）+ `big`: `管理模板`（进入 Backstage 模板管理） | 模板决定了纸张、页边距和格线类型，应放在「页面」最左侧第一位置。 |
| **2** | **纸张与边距** | `big_menu`: `纸张大小`（A4/A5/B5/16K）<br>`big_menu`: `纸张方向`（纵向/横向）<br>`big_menu`: `页边距`（普通/窄/适中/宽 + 自定义）<br>辅助行：当当前处于非空白模板时，在分组标题或工具提示清晰显示 **`（修改将转为自由空白页）`**。 | 解决用户调了页边距却不知道模板已自动切回空白页的困惑。 |
| **3** | **行距与排版** | Row 1: `行距` `NumberInput`（自由空白页可调；模板自带时提示 `模板自带`）<br>Row 2-3 或 `big_menu`: `排版规则 ▾`（标点避头尾、作文格两字母占一格、作文格分词不跨行） | 删除原来冗余的 `页面尺寸` 大按钮（其本质只是打开模板管理，已与 `管理模板` 重复）。 |

---

### 4.3 「手写」选项卡（消除空旷与深藏，直显高频调参）

**改造目标**：让用户能直接在 Ribbon 上看到并调节手写随机感和连笔，不再被迫点开 `10px` 箭头才能调任何参数。

**重组后分组顺序（左 → 右）**：

| 顺序 | 分组名 | 内部控件排列 | 调整理由与变更点 |
| --- | --- | --- | --- |
| **1** | **总开关与预设** | 左侧 `stack`: `随机排布` / `基础变形` / `字形变形`（三个 toggle）<br>右侧 `stack`: `连笔`（toggle）+ `智能偏移`（toggle，原藏在弹窗内）+ `风格预设 ▾`（工整 / 轻微自然 / 随性手写 / 恢复推荐） | 增加一键预设入口，降低新手调参门槛；释放 `笔画` 组单按钮占一组的浪费。 |
| **2** | **手写强度（高频直调）** | 3 行紧凑参数直显（带 `↘` 更多高级范围弹窗启动器）：<br>- Row 1: `字距`（紧凑 / 标准 / 宽松 或直接 min/max 快捷预设）+ `浮动`（无 / 轻 / 中 / 强）<br>- Row 2: `扭曲`（0~10 下拉）+ `倾斜`（0~10 下拉）+ `笔画`（0~2 下拉）<br>- Row 3: `连笔距离`（`%`）+ `连笔概率`（`%`）+ `随机轻重`（`±级`） | 把原来藏在 `StyleDialog` 中的核心直观调节项前置到 Ribbon；精细 min/max 数值再点 `↘` 高级范围。 |
| **3** | **多语种与混用** | Row 1: `英文` `[字体 ▾] [比例 ▾] [字形设置]`<br>Row 2: `数字` `[字体 ▾] [比例 ▾] [字形设置]`<br>Row 3: `多字体混用 ▾`（快捷查看当前混用列表、开关或直达字体库） | 接收自原「开始」页的 `中英文` 组；**两个 `"字形设置"` 按钮的 UIA `name` 分别设为 `"英文字形设置"` 和 `"数字字形设置"`**。 |
| **4** | **笔迹样本** | `big`: `换一组`（刷新随机种子）+ 紧凑种子号显示（如 `#48291`） | 保留高辨识度按钮，对齐分组高度。 |

### 4.6 右侧任务窗格（重构为「多模式检查器侧栏」）

彻底解决 `01c_tune_pane.png` 中 `字符微调` 挤掉 `设备` 控制区的问题。

1. **顶部改为互斥模式切换器（Segmented `TabBar`）**：

2. **`设备控制` 标签页内部重组（按频率从上到下）**：
   - **置顶状态栏**：`状态：空闲  X 0.00  Y 0.00`（使用等宽数字 + 状态着色徽标）；如有进行中任务 / `换纸提示` / `断点续写` 卡片，仅在激活时内嵌在此区域顶部，不占常态高度。

   - **低频折叠区（Collapsible Disclosure）**：
     - **`自定义命令`**（可展开/收起，默认有命令时展开紧凑按钮网格，无命令时单行提示 + `⚙` 编辑）；
     - **`串口控制台`**（默认收起为单行标题 + 最新 1 行状态预览，点击展开后显示 8~10 行滚动日志与输入框，释放 `~220px` 宝贵纵向空间！）。
3. **`字符微调` 标签页内部修复（`tune.rs`）**：
   - **修复标签折行**：将 `row()` 中的标签列宽从 `w(px(40.))` 增至 `w(px(54.))` 并添加 `.whitespace_nowrap()`，确保 `字体：`、`字号：`、`轻重：`、`微调：` 单行对齐。
   - **分离全局危险操作**：将底部的两个红色字体级操作（`字符重复轨迹优化`、`异常宽度字符处理`）移入末尾可折叠区 `"全局字体修复（作用于整套字体）"` 或附带确认提示与「在字体库中设置」链接，防止用户误以为只作用于当前选中单字。
